# Flowchart Builder

Paste textbook-style pseudocode, get a flowchart. Color it in, run it, and
save it as an SVG or a PNG.

```bash
python -m flowchart                     the studio, in your browser
python -m flowchart program.txt         one file, straight to .svg
python -m flowchart --site .            refresh the page this repo publishes
```

Nothing to install. Python 3 and nothing else.

## What is here

| | |
|---|---|
| [`flowchart/`](flowchart/README.md) | **the code** — a module per job, and what runs |
| `tests/run.py` | every check, in one command |
| `tests/programs/` | six pseudocode programs the checks draw, measure and run |
| `index.html` | the website's page (generated by `--site .`) |
| `.nojekyll` | tells GitHub Pages to serve the folder as it stands |

`__pycache__` folders appear wherever Python has run. They are its own
bytecode cache: never edited, safe to delete, and back the next time
anything runs. They are ignored by git and hidden in VS Code.

That is the whole repository. There is exactly one copy of the code, in
`flowchart/`, and every part of it can be imported on its own:

```python
from flowchart.parse.read import parse_program
from flowchart.make.chart import make_flowchart

svg = make_flowchart(open("program.txt").read())
```

[`flowchart/README.md`](flowchart/README.md) has the file-by-file table.

## The website runs this same code

`index.html` is the whole site and it needs no server. The page loads Python
into your browser (Pyodide, from a CDN), fetches the `flowchart/` package
sitting beside it, and runs it there — so a chart drawn on the website is
drawn by exactly the files in this repository. There is no build step and no
second copy of anything to keep in step.

**Publishing it.** On GitHub: *Settings → Pages → Source: deploy from a
branch, `main` and **`/ (root)`***. The root of the repository is the site.

After changing anything:

```bash
python -m flowchart --site .            # rewrites index.html
python tests/run.py                     # and know it still works
```

Only `index.html` needs rewriting, and only when the page's own HTML, CSS or
script changes. The Python is fetched as it stands, so editing a module
needs no rebuild at all.

In VS Code, Ctrl+Shift+B refreshes the page and Ctrl+Shift+P → *Run Task*
has the rest.
